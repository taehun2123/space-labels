# 설계와 식별 규칙

## 구성

| 구성 | 역할 |
| --- | --- |
| `SystemSpacesProvider` | SkyLight 읽기 함수로 디스플레이별 공간 UUID, 종류, 순서, 현재 공간 조회 |
| `DockAXScanner` | Mission Control의 Dock 접근성 트리에서 상단 공간 버튼과 앱 창 버튼 조회 |
| `OverlayMatcher` | 화면의 공간 순서와 시스템 목록을 대조한 뒤 표시 대상 확정 |
| `WindowIdentityResolver` | 개별 창 제목을 실행 중인 창 정보와 대조해 저장 가능한 키 판정 |
| `OverlayController` | 입력을 가로채지 않는 패널에 별도 이름 표시 |
| `AppController` | 이벤트 탭과 전역 이벤트 감시, 편집 창, 권한 상태, 메뉴와 설정 연결 |
| `NameStore`, `WindowNameStore` | 공간 이름과 창 이름을 각각 JSON에 저장 |

앱 아이콘 원본은 프로젝트의 `Assets/AppIcon.png`입니다. OpenAI 이미지 생성 도구로 겹친 창 두 개와 빈 이름표를 만든 뒤 1024픽셀 PNG로 저장했습니다. 빌드 스크립트가 크기별 PNG를 만들고 `AppIcon.icns`로 묶어 앱에 넣은 뒤 서명합니다. 메뉴 막대 아이콘은 같은 형태를 단색 템플릿으로 그려 macOS 화면 모드에 맞춰 표시합니다.

## 공간 이름

시스템 공간은 `uuid`, 실행 중 ID, 종류를 갖습니다. 이름은 UUID에 연결합니다. 같은 UUID가 서로 다른 실행 중 ID를 가리키거나 저장 기록에 중복되면 자동 연결을 중단합니다. 동일 공간이 두 디스플레이에 함께 나타나는 경우는 같은 실행 중 ID인지 확인합니다. 식별할 수 없는 이름은 삭제하지 않고 설정의 복구 목록에 둡니다.

상단 버튼은 Dock 접근성 트리의 `mc.spaces.list`에서 읽습니다. 디스플레이별 버튼 수가 시스템 공간 수와 같고, 일반 데스크톱 번호가 순서와 맞는 경우에만 연결합니다. 일치하지 않으면 표시와 우클릭 대상을 만들지 않습니다. 이 구조는 비공개 구현에 의존하며 OS 업데이트에 따라 바뀔 수 있습니다.

## 개별 창 이름

Mission Control의 `mc.windows`에서 창 버튼의 제목과 화면 위치를 읽습니다. 실행 중인 일반 창은 Core Graphics 목록으로 찾고, 창 제목은 접근성 API로 다시 읽습니다. 제목이 유일하게 일치하고 앱 식별자를 확인하면 `앱 식별자 + 원래 창 제목`을 저장 키로 사용합니다. 비공개 `_AXUIElementGetWindow` 함수를 실행 중에 찾아 창 ID도 확인합니다. 제목이 겹치더라도 실제 창 ID를 확인한 경우에는 앱 실행 중에만 쓰는 키로 구분합니다. 창 ID도 없으면 현재 Mission Control 화면에 한해 임시 키를 사용하고, 화면이 닫히면 지웁니다. 제목이 바뀌는 앱에서는 저장한 이름이 다시 연결되지 않을 수 있습니다.

우클릭은 듣기 전용 Core Graphics 이벤트 탭과 AppKit 전역 이벤트 감시를 함께 사용합니다. 같은 입력이 두 경로에서 들어오면 짧은 시간 안의 중복을 무시합니다. 최근 10초 안에 확인한 Mission Control 버튼 사각형 한 개에만 대응시킵니다. 공간 축소판과 이름 영역을 모두 우클릭 대상으로 삼습니다. 편집할 대상을 결정한 뒤 입력 창을 엽니다. 편집 과정에서 Mission Control이 닫힐 수 있습니다. 공간의 별도 이름은 상단 축소판 위 제목 영역에 표시하고, 이름 패널은 마우스 입력을 통과시킵니다.

## 데이터와 운영

공간 이름은 Application Support의 `local.spacelabels/names.json`, 저장 가능한 창 이름은 같은 폴더의 `window-names.json`에 기록합니다. 저장 전 이름을 검증하고 임시 파일을 만든 뒤 교체합니다. 이전 정상 파일의 백업을 유지하며 손상된 현재 파일을 따로 보존한 뒤 백업 복구를 시도합니다. 일반 설정은 UserDefaults에 둡니다.

SkyLight와 Mission Control 접근성 구조는 Apple의 공개 안정 API가 아닙니다. 시스템 데이터를 읽는 부분을 별도 파일에 모았으며 반환 형식이나 화면 구조가 예상과 다르면 임의로 이름을 연결하지 않습니다. [검사 결과](testing.md)와 [지원 환경](compatibility.md)을 함께 보십시오.
