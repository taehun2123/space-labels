# 호환성과 확인 상태

| 항목 | 상태 |
| --- | --- |
| 제작 환경 | macOS 26.6.2, Apple Silicon, Xcode 27.0 |
| SkyLight 공간 조회 | 이 Mac에서 1개 디스플레이와 일반·전체 화면 공간 목록을 읽는 시제품 확인 |
| 일반 데스크톱 설정 화면 | 초기 빌드에서 표시와 이름 입력 확인 |
| 전체 화면·Split View 공간 설정 화면 | 최신 빌드에서 전체 공간 7개와 저장된 이름 확인 |
| Mission Control 상단 표시와 우클릭 | 공간 7개 인식과 표시 패널 생성 확인, 우클릭 편집창은 열리지 않음 |
| Mission Control 개별 앱 창 표시와 우클릭 | 앱 창 8개 인식 확인, 우클릭 편집창은 열리지 않음 |
| 외장 디스플레이·Intel·다른 macOS 버전 | 미검증 |
| Developer ID 서명·Apple 공증 | 사용할 인증서가 없어 미수행 |
| 앱 아이콘 | 1024픽셀 원본에서 크기별 아이콘 묶음 생성과 Finder 표시 확인. 메뉴 막대의 실제 표시는 미검증 |

Mission Control의 접근성 구조가 바뀌면 이름 표시와 우클릭 편집이 멈출 수 있습니다. 공간 이름 파일은 그대로 보존합니다. 현재 앱은 개발용 임시 서명을 사용하며, 최신 빌드의 접근성 권한을 다시 등록해 인식 동작을 확인했습니다. 배포 준비는 [배포 문서](releasing.md)에 기록했습니다.
