# 사용 안내

## 시험판 설치

1. [Apple Silicon용 시험판 DMG](https://github.com/taehun2123/space-labels/releases/download/v0.1.0-preview.1/Space-Labels-0.1.0-preview.1-macos-arm64.dmg)를 내려받아 여십시오.
2. **Space Labels.app**을 **Applications** 폴더로 옮기십시오. 기존 앱을 교체하면 접근성 권한을 다시 등록해야 할 수 있습니다.
3. 앱을 여십시오. 이 시험판은 Apple 공증을 받지 않았으므로 macOS가 실행을 막을 수 있습니다. 이 저장소에서 받은 파일임을 확인하고 계속 사용하려면 **시스템 설정 → 개인정보 보호 및 보안**의 **그래도 열기**를 선택한 뒤 macOS 인증을 완료하십시오. [Apple의 앱 열기 안내](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)를 참고하십시오.
4. 앱의 **권한 설정 열기**에서 접근성 권한을 허용하십시오. 이미 허용으로 보이지만 앱에 적용되지 않으면 아래의 권한 복구 절차를 따르십시오.

이 시험판은 macOS 26.6.2의 Apple Silicon Mac에서 빌드했습니다. Mission Control의 우클릭 편집창은 아직 열리지 않습니다. [확인 상태](compatibility.md)를 보고 사용하십시오.

## 이름 바꾸기

Mission Control을 열고 상단의 데스크톱·전체 화면 앱·Split View 공간 또는 아래의 개별 앱 창을 우클릭하십시오. 입력 창에 이름을 적고 **저장**을 누르십시오. 이름은 앞뒤 공백을 뺀 1~40자이며 한글과 이모지를 사용할 수 있습니다.

현재 실기기에서는 우클릭 편집창이 열리지 않는 것을 확인했습니다. 공간 이름은 앱 설정 화면이나 메뉴 막대에서 입력할 수 있습니다. 개별 앱 창의 우클릭 편집은 아직 사용할 수 없습니다. 확인한 상태는 [검사 문서](testing.md)에 기록했습니다.

앱을 직접 열면 설정 창이 열립니다. 메뉴 막대의 겹친 창·이름표 아이콘에서 공간을 선택하거나 **이름 및 설정…**을 열어 공간 이름을 바꿀 수도 있습니다. 이름을 지우려면 설정의 **초기화**를 누르십시오. 저장한 앱 창 이름도 설정에서 초기화할 수 있습니다.

## 이름이 유지되는 범위

공간은 macOS가 제공한 UUID에 연결합니다. 공간 순서가 바뀌어도 같은 UUID면 이름을 유지합니다. 삭제되거나 식별자가 달라진 공간 이름은 **연결 확인이 필요한 이름**에 남기고 자동으로 다른 공간에 붙이지 않습니다.

앱 창은 앱 식별자와 원래 창 제목이 고유하게 확인될 때 이름을 저장합니다. 창 제목이 바뀌면 다시 표시되지 않을 수 있습니다. 창 ID만 확인한 경우에는 이번 앱 실행 중에만 유지합니다. 고유 식별자를 전혀 확인하지 못한 창은 Mission Control 화면을 닫으면 이름을 지웁니다. 입력 창에서 해당 범위를 안내합니다.

## 권한과 표시

Mission Control 항목 위치를 읽으려면 macOS 접근성 권한이 필요합니다. 설정에 권한 안내가 보이면 **권한 설정 열기**를 누르고 시스템 설정에서 Space Labels를 허용하십시오. 권한을 철회하면 이름 기록은 남지만 Mission Control 표시와 우클릭 편집은 멈춥니다.

시스템 설정에 Space Labels가 **허용**으로 보이는데 앱 설정에는 권한 안내가 계속 보인다면, 이전 임시 서명 빌드의 권한 항목일 수 있습니다. **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 기존 **Space Labels.app** 항목을 선택해 제거하고, **추가**로 현재 사용하는 `Space Labels.app`을 선택한 뒤 허용하십시오. macOS가 Touch ID나 암호를 요구하면 직접 인증하십시오. 앱을 종료했다가 다시 여십시오. 저장된 이름은 권한 항목을 지워도 유지됩니다.

설정 아래의 **최근 인식**에는 Mission Control에서 찾은 공간과 앱 창의 수, 편집 가능한 수가 표시됩니다. 그 아래에는 마지막 우클릭 입력을 받았는지, 해당 위치의 항목을 찾았는지가 표시됩니다. 우클릭이 반응하지 않으면 두 상태와 접근성 권한 안내를 확인하십시오.

화면 항목과 저장 대상을 안전하게 연결하지 못하면 해당 이름을 표시하지 않습니다. 이 앱이 종료되면 macOS의 기본 표시가 다시 보입니다. 이 앱이 덧씌운 글자는 macOS의 접근성 이름 자체를 바꾸지 않습니다.

공간과 창 이름은 이 Mac의 Application Support 폴더에 저장합니다. 현재 앱에는 이름이나 화면 내용을 네트워크로 전송하는 기능이 없습니다. 화면 접근 범위와 저장 구조는 [설계 문서](architecture.md)에 기록했습니다.

설정의 **로그인 시 실행**을 켜면 macOS 로그인 항목으로 등록합니다. macOS가 등록 승인을 요구하면 시스템 설정에서 완료하십시오.
